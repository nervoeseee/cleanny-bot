# Cleanny Bot — Система автоматизации клининговой службы

Telegram-бот для комплексной автоматизации бизнес-процессов клининговой компании.
Проект дублирует бизнес-логику сайта cleanny.by, дополняя её административной панелью,
системой учета рабочего времени, складским учетом и алгоритмом автоматического распределения заказов.

## Реализованный функционал:
### 1. Клиентская часть
Каталог услуг: Просмотр доступных услуг с описанием и базовой стоимостью. 
Калькулятор стоимости:
Краткий расчет (на основе базовой цены и количества комнат).
Полный пошаговый расчет (комнаты, санузлы, окна, дополнительные опции).
Все цены и коэффициенты вынесены в конфигурационный файл (`config.py`) для удобного редактирования.
Оформление заказа: Бесшовный переход от расчета к оформлению. Выбор даты, времени,
адреса и способа оплаты (Наличные, Терминал, Онлайн).
Отзывы: Просмотр последних отзывов и система оценки качества уборки (1-5 баллов) после завершения заказа.

### 2. Панель персонала (Уборщик)
Биржа заказов:Получение и принятие новых заказов.
Учет рабочего времени:Строгий контроль лимитов (не более 10 часов в день и 40 часов в неделю).
Автоматический учет времени на дорогу (30 минут до и после объекта).
Инвентарь:Просмотр списка необходимого оборудования на день. 
Обязательная отметка о сдаче инвентаря в конце смены (при невыполнении — автоматическая блокировка получения новых заказов).
График:Синхронизация расписания напрямую из Google Таблиц.

### 3. Панель администратора
Управление заказами:** Просмотр очереди заказов, ручное назначение исполнителей.
Автораспределение (Диспетчер): Фоновый планировщик автоматически назначает заказ на наименее загруженного сотрудника,
если заказ не принят в течение 1 часа.
Складской учет:Интеграция с Google Sheets. 
Автоматическое списание расходных материалов (химия, микрофибра) по нормативам при завершении заказа.
Статистика и отчетность:Подсчет выручки, количества заказов и среднего чека.
Выгрузка детализированного отчета в формате `.csv`. 
Инциденты:** Мгновенные уведомления администраторам при получении оценки 3 балла и ниже.

## Технологический стек
Язык:Python 3.10+
Фреймворк: Aiogram 3.x (Асинхронный Telegram API)
База данных: SQLAlchemy 2.0 + aiosqlite (SQLite)
Фоновые задачи: APScheduler
Интеграции: gspread + google-auth (Google Sheets API)

## Руководство по тестированию
Для удобства проверяющих в боте реализованы команды быстрого переключения ролей (без необходимости использовать несколько аккаунтов Telegram):
/admin — Получить права Администратора (доступно только для ID, указанных в ADMIN_IDS).
/staff — Переключиться в режим Сотрудника (Уборщика).
/client — Вернуться в режим обычного Клиента.

## Инструкция по развертыванию и запуску проекта
1.Создайте виртуальное окружение
2.Установите все необходимые библиотеки: 
pip install -r requirements.txt
3.Проект не будет работать без настроек. В корневой папке создайте файл .env и добавьте туда следующие данные:
BOT_TOKEN=
ADMIN_IDS=ID администраторов через запятую
GOOGLE_SHEETS_FILE_ID=
SERVICE_ACCOUNT_FILE=service_account.json
4.Создайте в корне проекта файл .env на основе .env.example и заполните его своими данными.
Создайте файл service_account.json на основе service_account.json.example. Получите свой ключ доступа в Google Cloud Console и вставьте его содержимое в этот файл.
5.Перед первым запуском необходимо создать таблицы в базе данных и наполнить их услугами. Для этого выполните скрипт:
 python add_services.py
6.Запуск бота:
python run.py
